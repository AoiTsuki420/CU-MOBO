# CU-MOBO:校准不确定性多目标贝叶斯优化

**面向昂贵 + 不确定 oracle 的、把校准不确定性作为一等目标的约束多目标逆向设计方法。**

> 原理驱动,不含任何"动物隐喻"元启发式。内层用贝叶斯优化(昂贵 MOO 的 SOTA 级框架)。

## 1. 问题设定

逆向设计在搜索空间 `x ∈ X`(如生成模型隐空间 `z`)上找高性能候选。每次评估调用一个
**昂贵**且**不确定**的 oracle(如 KcatMoE 给酶动力学 kcat、Boltz 给结构),它返回:

- 预测活性 `μ(x)`(point estimate);
- **校准**不确定性 `σ(x)`(如集成/conformal,σ 与真实误差正相关);
- 其它确定性目标(QED 成药性、SA 可合成性);
- 约束(SMILES 有效、Lipinski、PAINS、尺寸)。

真正想要的是**真实活性 `a_true`**,而非预测 `μ`。

## 2. 失效模式:oracle-gap(本方法要解决的核心问题)

朴素 `μ`-贪婪逆向设计会**系统性地利用 oracle 过自信但错误的区域**:在某些 `x`,`μ`
被高估(看起来高活性)但 `a_true` 低。**校准 σ 在这些区域会升高**(oracle 自己示警),
但 μ-贪婪忽略 σ → 落入陷阱 → 预测高、真实低(oracle-gap 大)。

## 3. 三个原理性机制(= 方法贡献)

1. **σ 作一等目标**:Pareto 优化 `[μ↑, −σ↑(可信度), QED↑, −SA↑]`。把 `μ−λσ` 标量
   选择升级成**显式前沿**——无 λ 超参,风险偏好在前沿上事后取点。

2. **校准 σ 作异方差观测噪声(核心算法新意)**:活性的 GP 代理用 oracle 的 `σ²(x)`
   作 **per-point 观测噪声**(`train_Yvar`)。于是 GP 后验**自动下采信高 σ 的不可靠
   观测、上采信低 σ 的可靠观测** → 后验均值是去噪的真实活性估计 → 直接抵抗 oracle-gap。
   标准 MOBO(qEHVI/qNEHVI)假设无噪声或同方差,丢掉了 oracle 给的这份校准信息。

3. **风险感知批量采集 + 约束**:`qNEHVI` 在上述目标上批量(q 点/轮)选点,样本高效;
   约束用可行性加权。

> 2×2 消融(σ-作目标 × σ-作噪声)可独立验证机制 1、2 的贡献。

## 4. 验证协议:打破"自评循环"的 in-silico 版

逆向设计论文的头号风险是**循环论证**(用 oracle 引导生成、又用同一 oracle 评估)。
本方法用一个**合成不确定 oracle 基准**做可控、可证伪的验证:

- 已知**真实活性 `a_true(x)`**,但优化器**看不到**;
- oracle 给 `μ = a_true + 陷阱bump(x)`、`σ = σ0 + γ·bump(x)`(**校准**:σ 跟踪误差);
- 优化器只用 `(μ, σ, qed, sa)` 搜索;
- 最后用隐藏的 `a_true` 算指标:**true-activity↑、oracle-gap = |μ−a_true|↓、陷阱占比↓**。

预期:CU-MOBO(用 σ)在 true-activity / oracle-gap 上显著优于忽略 σ 的 naive μ-贪婪。

## 5. 与 SOTA 的定位(诚实)

- 内层 BO/qNEHVI 是昂贵 MOO 的强基线;本方法**不主张新优化器原理**。
- 贡献 = **校准不确定性的一等目标化 + 异方差去噪 + oracle-gap 验证协议**在逆向设计上的
  原理性实例化与实证。属应用/方法学贡献,定位 AI4Science / 应用刊,而非算法顶会"新 SOTA"。
- 对照集应含:naive μ-greedy、qNEHVI(忽略 σ)、qParEGO、NSGA-II,以及 2×2 消融。

## 6. 诚实边界

- 合成基准证明机制有效;真实闭环仍需把候选送**真实 KcatMoE/Boltz**,且 true-hit 用
  **独立 oracle**(见 molgen `PAPER_PLAN_inverse_design.md` §3)。
- σ 必须**真校准**才有效;未校准 σ 当噪声/目标无益甚至有害(应作对照)。
